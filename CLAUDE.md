# Claude — start here

- If you were sent this repo **from an installation project** — sent from a `[TD]` project or from
  `otakoyi-td-template` (TouchDesigner), or from a browser engine, Unreal, … — to make that
  installation controllable: read `docs/integration.md` and follow it (short version:
  `skills/otakoyi-integrate/SKILL.md`). The output of that task lives in the installation repo
  (`otakoyi/osc-contract.json` plus OSC in/feedback wiring), not here. Studio TD rules stay in
  `otakoyi-td-template`; this repo owns the pult side.
- If you are working **on this repo**: read `AGENTS.md` first; its hard rules and workflow apply.
