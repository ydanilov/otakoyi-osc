# Changelog

Design-system changes, newest first. Add an entry in the same PR as the change; mention renamed
Figma components or variants explicitly (they are exporter API, ADR-014).

## 2026-10-22 — code = Figma parity, sizes, picture pads, debug overlay

**Changed**

- Depth tokens are the Figma effect styles 1:1: Neu/Raised, Raised SM, Inset and Pressed are lit
  from above (no diagonal offsets); glow is Glow/Primary (8 + 2) at rest and Glow/Primary Active
  (12 + 3) while pressed / touched (was 14 + 4 everywhere). Continuous corners on iOS.
- **Fader** (absolute / crossfade): recessed rail, thin lit value line, raised thumb with LED and
  grips, ticks beside the rail (spread ×1.8 in fine mode); fine mode lights it in the accent with a
  focus ring around the thumb. No more solid lime slot.
- **Fader Mode=Relative**: a jog wheel — recessed housing, cylinder ribs that roll with the drag,
  lit detent marks, − / +.
- **Knob**: arc track, lit value arc, well, raised disc, cap and indicator dot, end stops
  (Relative: dot ring with lit dots and a knurled disc; Color: spectrum over the 240° face and a
  colour swatch). New `size: "compact"` (dial ≈ 0.7×).
- **Tab Bar / Screen Tab** and the pult's screen tabs: a recessed capsule track with a raised
  capsule tab. **Segmented**: raised capsule housing with the selected option as an inset capsule
  and a glowing label — never a lit fill.
- **Pads** (Pad, Toggle, Button Grid, Scene List, Button Group): raised keys; on = lit ring + soft
  glow on a pressed-in key with a lit ON caption / LED strip; a momentary pad is lit only while
  held. New `size` (150×88 / 104×64).
- **List Card**: inset separators from the row text (50 pt). **List Row**: 20 pt icons, 14 pt gap.
  **Switch**: Figma size (104×46 track, 58×40 thumb); in rows only the trailing LED.
- Pult pager: page dots under the screens.

**Added**

- **Picture pad** (Toggle Content=Image): `image` from the config's asset bundle; label on a
  legibility gradient, off dims the image, on adds the lit ring + LED.
- **Debug Tag** and **Debug HUD** (Settings › Developer › Debug overlay), backed by `DebugStore`.

## 2026-10-22 — navigation per Apple HIG, no client login (ADR-012, ADR-013, ADR-004)

**Changed**

- Pult Header: leading **Settings** and trailing **Installation** icon buttons.
- Settings / Installation: system sheets (`presentationFor`), iPad Installation **Inspector**
  (390 pt, no dimming). Edge swipes are shortcuts (`EdgeSwipe`; left edge phone only).
- **Dialog** is content only (no background, grabber, scrim or home indicator); it sits in the
  native sheet / form sheet.
- **Scrim** dims only (no blur); `expo-blur` removed.
- Copy: “Sign out” → “Forget this installation”; no appearance switch or brand editor in the app.

**Added**

- **Toast** (text + optional action, 5 s), **Context Menu** (long-press with preview) and
  **Pull-down Menu** (image source picker) — native SwiftUI menus on iOS via `@expo/ui`.
- Connect: **Connect Options**, **Connect Form** (address + PIN, `manualPairing`), **Backdrop**,
  **Client Logo**, **Client Loading** screen.
- Stories for the new control types (ADR-015): Fader relative/crossfade, Knob relative/hue,
  Thumbstick, Button Group, Image, Mic, Prompt, switch-style Toggle, control LED.

**Removed**

- Custom swipe drawers (`Drawer`, `DrawerEdge`).

## 2026-10-22 — design-system components and Storybook

**Added**

- Storybook (React Native Web + Vite) in `apps/storybook`: theme, brand and viewport switchers,
  autodocs for every component, `play` interaction tests, a11y addon. Introduction, Guidelines and
  this Changelog.
- Depth tokens: `elevation.*` in `tokens.json` (dark + light), `boxShadow(theme, depth, glow)` and
  the `Surface` primitive (Neu/Raised, Raised SM, Inset, Pressed, flat; Glow/\*).
- Phosphor icons (`ds/icons.ts`, Figma `Icon/<name>`) and `Glyph`, `Led`.
- Chrome: Button, Icon Button, Badge, Connection, Status Banner, Screen Tab, Tab Bar, Top Bar,
  Nav Item, Brand Mark, Wordmark, Stat Tile, Note, Info Card, Chip, Loader, Divider, Scrim, Page Dots.
- Forms: Input (`TextField`), Value Input, Select (native SwiftUI menu on iOS via `@expo/ui`),
  Stepper, List Row, Switch (`LedSwitch`).
- Containers: List Card, Section, Console Panel, Dialog (sheet / modal by width), Release Note,
  Release Card, Pult Card, Viewfinder.
- Media & actions: Quick Action (with hold), Master Bar, Activity Row, Image Tile, Image Upload,
  Progress Ring (UI only).
- Patterns: Quick Actions Row, Installation Actions, Installation Switcher, Activity Log,
  Stepper Group.
- Stories for every existing control, the pult renderer and the Reusables primitives.

**Changed**

- `PultHeader` uses `ConnectionStatus` and `StatusBanner` (neumorphic inset banner, solid studio bar).
- `ThemeProvider` exposes `ThemeLayer` to re-apply the brand inside RN `Modal`s.
