# Decisions

Why Otakoyi Control is the way it is. Each decision is a short record: the context, what was
decided and what follows from it. A decision is never edited to say something new; a later one
replaces it, and the old one stays here, dimmed, so the history is visible.

Read a decision before changing what it covers. To change it, write a new one.
